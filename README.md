# MetaDataGovernance

MetaDataGovernance is a project for documenting and extending metadata
governance practices based on [OpenMetadata](https://github.com/open-metadata/OpenMetadata).
OpenMetadata is the upstream open-source project that provides the metadata
catalog, governance model, and APIs used as the foundation for this project.

## Scope

This repository is intended to collect governance-focused guidance and
integrations around:

- data ownership and stewardship;
- business glossaries, classifications, and tags;
- access policies and compliance controls; and
- auditability and metadata quality.

Refer to the [OpenMetadata documentation](https://docs.open-metadata.org/) for
the upstream product architecture, APIs, and deployment instructions.
